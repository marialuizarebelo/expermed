# Script Cadência de E-mails — Escritórios Trabalhistas

**IMPORTANTE:** este script é para um tipo de lead diferente do fluxo atual
do projeto — parceria com escritório de advocacia (o escritório encaminha
demandas periciais dos próprios clientes pra Expermed), não uma empresa-alvo
com processos trabalhistas. Não está ligado ao pipeline de Apollo/geração
de mensagem atual. Mantido aqui só de referência, caso decidam prospectar
escritórios no futuro.

Fonte: PDF original enviado pela Mariana. Placeholder `XXXXX` = nome do
escritório/advogado.
